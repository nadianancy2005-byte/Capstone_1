# Capstone 1: Texas Sales Analysis

## Project Overview
This project analyzes Texas sales performance for EmporiUm using SQL and Excel. The goal is to understand revenue trends, compare regional performance, evaluate product categories, and identify opportunities to improve sales.

## Tools Used
- MySQL Workbench
- SQL
- Microsoft Excel (PivotChart)
- Git and GitHub

## Analysis Questions
1. What is the total Texas revenue and transaction date range?
2. How much revenue did Texas generate each month and year?
3. How does Texas revenue compare with the South Region?
4. What are the monthly transaction counts and average sales by product category?
5. How do Texas stores rank by total revenue?
6. What should the business prioritize next quarter?

## Key Findings
- Total Texas revenue: $3,417,850.01
- South Region revenue: $7,996,850.12
- Texas contributed 42.74% of South Region revenue.
- Highest-performing Texas store: Beaumont ($637,818.90).
- Lowest-performing Texas store: Dallas ($54,444.05).
- Technology & Accessories had the highest average sale amount in January 2022 ($369.82).

## Excel PivotChart
I created a PivotChart showing Texas monthly revenue from 2022 to 2025. The chart compares monthly sales across four years to help identify revenue trends.

## Business Recommendations
I recommend investigating lower-performing stores like Dallas, studying successful strategies from Beaumont, and using monthly sales trends to improve marketing and inventory planning.
